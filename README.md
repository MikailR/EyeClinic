# The Eye Clinic — website prototype bakeoff

Five **mobile-first ophthalmology clinic website** prototypes for [Dr. Shehenaz Mohammed](https://github.com/MikailR)’s practice in Trinidad (Chaguanas + Tacarigua), each generated by a different local CLI/model against the same brief.

Live comparison board: **https://mikailr.github.io/EyeClinic/**

## Branches

| Branch | Tool | Model | Preview |
|---|---|---|---|
| [`grok-4.6`](https://github.com/MikailR/EyeClinic/tree/grok-4.6) | Grok CLI | grok-4.6 | [live](https://mikailr.github.io/EyeClinic/previews/grok-4.6/) |
| [`fable-5.1`](https://github.com/MikailR/EyeClinic/tree/fable-5.1) | Claude Code | claude-fable-5-1 | [live](https://mikailr.github.io/EyeClinic/previews/fable-5.1/) |
| [`opus-5`](https://github.com/MikailR/EyeClinic/tree/opus-5) | Claude Code | claude-opus-5 | [live](https://mikailr.github.io/EyeClinic/previews/opus-5/) |
| [`gpt-6-astra`](https://github.com/MikailR/EyeClinic/tree/gpt-6-astra) | Codex CLI | gpt-6-astra | [live](https://mikailr.github.io/EyeClinic/previews/gpt-6-astra/) |
| [`claude-design`](https://github.com/MikailR/EyeClinic/tree/claude-design) | Claude Code + Design MCP | claude-fable-5-1 | [live](https://mikailr.github.io/EyeClinic/previews/claude-design/) |

`main` holds this comparison host + built preview snapshots under `/previews/<branch>/`.

## How to compare

1. Open the [live board](https://mikailr.github.io/EyeClinic/) on your phone.
2. Or open a single preview from the table above.
3. Locally: `git checkout <branch> && npm install && npm run dev` (or open `index.html` if the branch is static).

---

Same bakeoff pattern as [MikailR/GUI](https://github.com/MikailR/GUI). Box-local CLI stack — no CloudAgent for generation.
